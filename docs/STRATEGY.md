# Product Website Strategy

## Positioning

Whano keeps Shopify orders moving after checkout through instant automated WhatsApp messaging.

## Audience

Egyptian Shopify merchants selling physical products who want a dependable, zero-setup way to automate the repetitive conversations after an order is placed.

## Five-second message

Whano connects Shopify to WhatsApp and handles the conversation after an order: confirmation, changes, delivery updates, and reviews — with zero number setup.

## Primary conversion

Request access / Install on Shopify. Centralized in `src/data/content.ts`.

## Objections addressed

- Does it require a new WhatsApp number or complex API setup? The FAQ explains that Whano uses unified verified WhatsApp infrastructure, requiring zero number setup or phone linking.
- Will the messages sound robotic? The page shows native Egyptian Arabic and explains template control.
- Can customers change orders? The feature section explains additions, quantity changes, and cancellation before fulfillment.
- What happens when automation is not enough? The page explains human handoff and pause behavior.
- How is usage priced? The page shows points packs in EGP without pretending they are a monthly subscription.

## Section purposes

| Section | Purpose |
|---|---|
| Hero | State the post-checkout positioning and show the product immediately |
| Problem | Make the operational cost of manual follow-up concrete |
| Flow | Explain the order lifecycle in the order it happens |
| Features | Describe the four useful automations without vague feature marketing |
| Control | Establish Shopify as the source of truth and the merchant as decision-maker |
| Pricing | Remove the price objection with transparent packs |
| FAQ | Resolve practical objections before the CTA |
| CTA | Offer one clear next step |
